How to read this. Portable key = a real API key you can paste into any tool or script. Client-bound = usage only inside the vendor's own app; no key to extract. Keyless = no signup at all. Cloud credit = card-backed grant that expires.

Allowance caveat. Daily quotas and one-time grants are not equivalent — a 200K/day cap renews, a 100M one-time grant does not. The unit is shown in every row. Sorting by allowance compares the raw number, so read the unit before drawing conclusions.

Refreshed daily. Data lives in data.js; this page is the stable view. Every run appends to CHANGELOG.md and archives a dated snapshot under archive/.

Verification. Base URLs, model IDs and limits are read from each provider's own documentation or console. Promotional terms change without notice — several have live countdowns rather than published dates. Confirm on the provider's page before relying on any figure. Never use a shared or resold API key: no provider issues those, and whoever issued them can read your traffic.
