Set it up

  1. Go to developer.amd.com.cn/en/radeon/tokenfactory — the /en/ path gives English labels.
  2. Click 登录 / Log in top-right, choose the verification code tab.
  3. Enter your email → 发送验证码 / Send code → enter the 6-digit code. No card, no ID check.
  4. Click a model under Public Free Model APIs, copy the API Key (starts sk-).
  5. One key drives every free model — no separate key per model.

Test it

curl https://developer.amd.com.cn/radeon/api/v1/chat/completions \ -H "Authorization: Bearer $AMD_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model":"DeepSeek-V4-Flash","messages":[{"role":"user","content":"Hello"}]}'
