Watch out
Google's own pricing table marks free-tier content as used to improve their products. Paid tier says no. This disqualifies the free tier for client code, proprietary source, or anything under an NDA. Pro models are not free at all.
Worth knowing
Endpoint quirk: the native path wants ?key= as a query parameter, not a Bearer header. Use the /openai/ path shown above and your existing OpenAI code works unchanged.

Set it up

  1. Go to aistudio.google.com/apikey, sign in with a Google account.
  2. Click Create API key. Pick an existing Cloud project or let it create one.
  3. Copy the key — starts with AIza.

Test it

curl https://generativelanguage.googleapis.com/v1beta/openai/chat/completions \ -H "Authorization: Bearer $GEMINI_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model":"gemini-3.5-flash","messages":[{"role":"user","content":"Hello"}]}'
