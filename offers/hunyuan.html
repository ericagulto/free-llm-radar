What this is

Tencent's Hunyuan Hy4 preview, a 770B mixture-of-experts model with a 1M-token context window. New users get 14 days of daily free quota; existing users get free usage during night hours instead.

What it's good for

  • Very long-context work — 1M tokens is the largest context window on this list
  • Chinese-language tasks
  • Evaluating a 770B MoE model without infrastructure

Caveats and red flags

  • Text-only. Image and video tasks route to other models and bill normally.
  • The new-user allowance ends 10 October.
  • You switch models inside WorkBuddy or CodeBuddy rather than through a key.
  • The 1M context is impressive but most tasks do not need it, and long prompts cost accordingly.

Reviews and reputation

Thin independent coverage Mostly Chinese-language coverage. The 1M context claim has attracted attention but independent long-context benchmarking is limited.

What we could verify

  • Hy4 is a 770B MoE model with a 1M-token context window, text-only. Source: Tencent Hunyuan documentation
  • Tencent Cloud TokenHub gives new users 1M tokens for the Hy4 preview API as an alternative route. Source: Tencent Cloud console
Our take opinion

The context window is the headline and it is genuinely the largest here. Read the text-only caveat first — if you were planning to feed it screenshots or audio, that routes elsewhere and bills. Also note there is a separate API route via Tencent Cloud TokenHub if you want a key rather than the in-app switch.
