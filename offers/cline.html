What this is

Cline rotates a changing set of models to free inside its VS Code coding agent. You look for models carrying the FREE tag in the model picker.

What it's good for

  • Agentic coding inside VS Code with no API key at all
  • Trying newly released models the day they appear in the picker
  • Using your own portable key through a mature open-source client

Caveats and red flags

  • The free roster rotates with no notice, so a workflow that depends on one model can break overnight.
  • Client-bound — there is no public Cline API.
  • Free availability is a vendor arrangement, not a tier you control.

Reviews and reputation

Some independent coverage Cline is well covered as an open-source coding agent. The rotating free-model promotion is discussed mainly in community channels and changes too often to be documented reliably.

What we could verify

  • Free models are marked with a FREE tag in the model picker and rotate over time. Source: Cline documentation
  • Cline accepts external provider keys, so it can be used as a client for a portable provider. Source: Cline documentation
Our take opinion

The most interesting thing about Cline is not the free models — it is that Cline accepts your own keys. Pair it with an AMD or Groq key and you have a mature agent client on top of a provider you control, which is a better arrangement than depending on whichever model happens to be free this week.

Set it up

  1. Install from cline.bot — pick your editor (VS Code, JetBrains, or CLI).
  2. Sign in with a Cline account.
  3. Open the model selector and pick a model carrying the FREE tag.
  4. Work. When the quota runs out it offers ClinePass at $9.99/month.
