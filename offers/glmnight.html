What this is

Z.ai's GLM Coding Plan makes GLM-5.3-Flash free to use during night hours. It is a scheduling offer: the model is free, but only at certain times.

What it's good for

  • Overnight batch work and unattended agent runs
  • Scheduling long jobs into the free window

Caveats and red flags

  • Night hours only — useless if you work during the day.
  • Client-bound, single model.
  • Extended once already, so the end date can move in either direction.

Set it up

  1. You need an active paid GLM Coding Plan — the campaign covers paying subscribers only, not free accounts.
  2. Use ZCode 3.10 or later (or AutoClaw) during the window. The discount applies automatically inside 23:00–09:00 Beijing time; there is nothing to claim.
  3. Select GLM-5.3-Flash specifically — every other model keeps consuming quota normally.
  4. Plan around the 5-hour/week cap: once you hit it, the night window is closed to you until the limit resets.
