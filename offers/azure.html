What this is

Azure AI Foundry's $200 credit, valid 30 days, covering Azure OpenAI and the broader model catalogue.

What it's good for

  • Evaluating Azure OpenAI where your organisation already runs on Azure
  • Enterprise-shaped prototyping with Azure's compliance posture
  • Model catalogue access beyond OpenAI models

Caveats and red flags

  • Auth is an api-key header plus an api-version query parameter — not a Bearer token. Existing OpenAI code will not work unchanged.
  • 30-day window.
  • A card is required.
  • The smallest credit of the three major clouds.

Reviews and reputation

Some independent coverage Azure OpenAI is very widely covered. The Foundry credit specifically gets less attention than the service itself.

What we could verify

  • $200 credit valid for 30 days, requiring a payment method. Source: Azure free account terms
  • Requests use an api-key header and require an api-version query parameter. Source: Azure OpenAI documentation
Our take opinion

The weakest of the three cloud grants on raw numbers, and the one whose API shape costs you the most setup time. Choose it because your organisation already lives in Azure, not because of the $200.
