What this is

Ling 3.1 Flash is a coding- and agent-oriented model that Ant's InclusionAI released on 30 September 2026 — roughly 560B total parameters with about 25B active per token. It is free to call through Vercel AI Gateway and Command Code until 13 October 2026, at $0.00 for both input and output.

What it's good for

  • Trying a brand-new frontier-class coding model with no signup, no card, and no vendor account — the gateway is the fastest route onto it
  • Agent and tool-calling workflows, which is what the model was tuned for
  • Long-document work up to the 262K context the gateway exposes
  • A free fallback in Command Code if you already pay for the Go tier

Caveats and red flags

  • Two model IDs behave differently at the end: the standard ID starts billing, the -free ID stops serving. Pick -free unless you intend to pay.
  • Command Code is not free — the model is free on it, but the client needs a paid Go-tier subscription or above.
  • The gateway caps context at 262K, not the 1M the model itself supports.
  • Command Code limits you to about 300 requests per day per account.
  • This is a gateway promotion of a vendor model, not an Ant free tier. Ant has published no public free allowance of its own, so there is no first-party fallback when this ends.

Set it up

  1. Easiest route: sign in to Vercel AI Gateway and pick inclusionai/ling-3.1-flash from the model list. No separate vendor signup.
  2. In code, use inclusionai/ling-3.1-flash-free — the -free ID stops serving when the promotion ends instead of silently billing you.
  3. Coding-agent route: install Command Code, subscribe to Go or above, then run cmdc --model inclusionai/ling-3.1-flash:free.
  4. Use it before 13 October. After that the plain model ID starts billing and the -free ID is switched off.
