What this is

OrcaRouter is a model gateway that keeps a rotating set of model ids priced at $0 per token. The free ids shadow real catalog models — DeepSeek V4 Flash, GLM-5.3-Flash and Tencent's Hunyuan Hy3 and Hy4 preview among them — and the vendor states they carry no trial clock and do not expire while they stay in the lineup. What matters here is the key: unlike a client-bound coding tool, this one can be pointed at your own software.

What it's good for

  • Pointing an existing OpenAI-compatible client at a free DeepSeek or GLM model without opening an account with either vendor
  • Claude Code and other Anthropic-protocol tools — the endpoint accepts the Anthropic and Gemini request shapes as well as OpenAI
  • One router id, orcarouter/free, that picks a light or a strong free model per request instead of you choosing each time
  • Cross-checking a model you already pay for elsewhere, at zero cost

Caveats and red flags

  • An account that has never topped up gets 10 requests per minute and 50 per day — an evaluation allowance, not a working one.
  • The always-free ids are gated on the workspace owner linking an established GitHub account. A freshly created GitHub account has a waiting period.
  • A per-request prompt-size cap applies on the unpaid tier and the vendor does not publish the number. A long prompt fails with a 400, not a 429, and retrying it unchanged fails forever — so a script that works on short prompts and fails on long ones has hit this, not a rate limit.
  • Free ids never fall back to the paid model. That is a feature — no surprise billing — but it also means no graceful degradation when free capacity is saturated.
  • No X-RateLimit headers are sent on free traffic, so there is no way to read how much of a window is left.
  • The lineup rotates. A model can leave without notice, and only the vendor's public list says what is free today.

Our take opinion

Worth listing for one reason: it is a free tier that hands you a key instead of trapping the models inside somebody else's editor, and it carries the Hunyuan Hy3 and Hy4 models that are otherwise locked to Tencent's own clients. The 50-requests-a-day unpaid tier is honest about what it is — enough to decide whether a model suits you, not enough to lean on. Set it up

  1. Create an account at orcarouter.ai/register — no card required for the free models.
  2. Link a GitHub account with some history, or sign in with one. The always-free ids are gated on this; a freshly created GitHub account needs a waiting period, and a paid top-up of any amount also unlocks them.
  3. Copy the API key and point any OpenAI-compatible client at the base URL.
  4. Call a model id ending in -free — or orcarouter/free, a single router id that picks a light or a strong free model per request by scoring difficulty.
  5. Read the live list rather than hardcoding ids: GET /api/free-package/public is public and needs no key.
