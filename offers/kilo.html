What this is

Kilo Code is an open-source coding agent for VS Code, JetBrains, the CLI and the cloud, with an MIT-licensed core. Alongside paid and bring-your-own-key routes it runs a free hosted tier — Auto Free — that routes your requests to models currently priced at zero input and zero output.

What it's good for

  • Everyday code generation, refactoring and debugging at no cost
  • Evaluating new model releases as they appear on the free list
  • A single picker that also reaches your own AMD or Groq key, or a local Ollama model

Caveats and red flags

  • Free hosted inference is not the same as free-to-download weights — the promotion can end whenever the provider changes its pricing.
  • Several free models train on your prompts. Check the model page before sending anything sensitive.
  • Free-tier requests can be routed to whichever model is available, so output quality is not consistent run to run.

Set it up

  1. Install Kilo Code into VS Code, JetBrains or the CLI.
  2. Create a free Kilo Cloud account — no credit card required for the free models.
  3. Open the model picker and choose Auto Free, or any model marked Free.
  4. Work. Switch to a paid, local or BYOK model whenever your task changes.
